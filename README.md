# Проект тестирует сервер с обработчиком /cafe, принимающим параметры:

city (обязательный, значения: moscow, tula);

count (количество возвращаемых кафе; если не указан — возвращаются все);

search (строка поиска в названии кафе, без учёта регистра).

Ответ сервера — строка с названиями кафе, разделёнными запятыми (например: Пир и мир, Красиво есть не запретишь, Поздний завтрак).

## Задача: написать в main_test.go два теста с использованием пакетов assert и require:

TestCafeCount() — проверить обработку параметра count для значений 0, 1, 2, 100 (сверив длину списка кафе после разбиения строки через strings.Split).

TestCafeSearch() — проверить поиск по search в Москве (city=moscow) для строк фасоль (0 кафе), кофе (2 кафе), вилка (1 кафе); для проверки совпадений использовать strings.Contains после приведения к единому регистру (strings.ToLower/strings.ToUpper).

## Критерии успеха:

- команда go test . выполняется без ошибок;

- в main_test.go присутствуют четыре функции: TestCafeWhenOk(), TestCafeNegative(), TestCafeCount(), TestCafeSearch().
